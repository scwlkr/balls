# ADR 0003 — Use Apache License 2.0

- **Status:** Accepted
- **Date:** 2026-08-19

Balls will use Apache License 2.0 because broad adoption, commercial flexibility, and an explicit
contributor patent grant are more important than forcing downstream or hosted modifications to be
published. Incoming contributions use the same license without a CLA or copyright assignment
unless a later recorded business need changes that policy.

The repository includes the canonical license text in [`LICENSE`](../../LICENSE) and its current
attribution status in [`NOTICE`](../../NOTICE). No third-party attribution notices are required for
the current source distribution. Future dependencies or copied source that require attribution
must update `NOTICE` before distribution.

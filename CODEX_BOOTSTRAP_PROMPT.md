# Codex Continuation Prompt

Work autonomously from the active Balls milestone.

1. Read `AGENTS.md`.
2. Read `docs/STATE.md`.
3. Open the active GitHub milestone and select the highest-priority unblocked issue labeled
   `ready-for-agent`.
4. Read only that issue and the deeper documents it links.
5. Complete every acceptance criterion, run the smallest honest gate, update evidence/state, open
   one pull request, and squash merge when required checks pass.
6. Continue to the next ready issue unless publication, secrets, spending, an irreversible action,
   or a genuinely unresolved owner decision requires a stop.

Do not rebuild the full product vision from this prompt. The repository documents are the source
of truth, and the issue is the execution contract.
